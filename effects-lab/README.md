# Effects Lab

Demo viết lại bằng code và asset riêng, dựa trên phân tích REA. Mỗi file chạy độc lập, mở thẳng trên trình duyệt.

| Tên | File | Mô tả ngắn | Nguồn tham chiếu |
|---|---|---|---|
| Silhouette Text Flow | `silhouette-text-flow.html` | Mô hình 3D xoay khi scroll, chữ hai cột trượt lên và bị đẩy sang hai bên theo viền nhân vật | unbelievablycrap.com |
| Ink Mask Reveal | `ink-mask-reveal.html` | Khung nét thô có sẵn, bản hoàn chỉnh loang vào như nét mực khi scroll | heronaiapp.com |
| Warp Fill | `warp-fill-sheet-rise.html` | Vệt mực WebGL mở từ tâm thành màu nền chương sau | grail-app.com |
| Sheet Rise | `warp-fill-sheet-rise.html` (cuối trang) | Tấm Paper chương sau trượt lên che, nghiêng rồi phẳng dần | grail-app.com |
